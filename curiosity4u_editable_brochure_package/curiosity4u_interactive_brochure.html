Clean Slate Every Session

Best for: Practical exams, coding tests, and shared daily practice labs.

  • • Auto-Wiped on Exit: All files and history erase automatically when the session ends.
  • • 100% Exam Integrity: Next student batch never sees files left behind by previous students.

Student Files Saved Across Sessions

Best for: Semester-long coursework, capstones, and multi-week projects.

10 · Security & Exam Integrity

Built for strict, cheat-proof practical exams.

🛡️

1. Isolated Container Sessions

Every student runs inside a dedicated, resource-capped Linux container. Zero shared folders or visibility into other students' workspaces.

🔒

2. Kernel Network Sandboxing

Host-level iptables rules block lateral container-to-container packets—stopping LAN chat, local file transfers, or SSH copying.

🚫

3. One-Click Internet Lockdown

Disable external web browsing and AI tools during practical exams while keeping compilers, IDEs, and the local portal active.

🧹

4. Automatic Post-Exam Wipe

In non-persistent exam mode, containers self-destruct when the timer ends—leaving zero code behind for the next exam shift.
