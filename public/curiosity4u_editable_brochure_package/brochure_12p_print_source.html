07 · Flexible Storage Architecture

Two storage plans built for your courses.

PLAN A · EPHEMERAL Base Price: [Base Price / Student]

Non-Persistent Storage

Best for: Practical examinations, daily coding drills, and shared computer labs.

  • Automatic Session Wipe: All student files and history are permanently erased the moment the session ends.
  • 100% Exam Fairness: Next batch of students never sees code or answers left behind by the previous batch.
  • Zero Disk Maintenance: Server storage never fills up across semesters.
  • One-Click File Export: Students can still download their code before ending a practice session.
Included in Base Plan · Zero storage overhead on your campus server.
PLAN B · PERSISTENT HOME Add-On: [+ Extra Cost / Student]

Persistent Storage

Best for: Semester-long projects, capstone teams, and continuous lab coursework.

  • Files Saved Across Sessions: Each student's /home folder automatically mounts every time they sign in.
  • Enforced Per-Student Quotas: Built-in Disk Guard prevents any single user from exhausting server storage.
  • Live Usage Visibility: Top bar displays real-time quota usage (e.g., Saved home · 203 / 1024 MiB used).
  • Automated Backups: Snapshot and recovery support for long-running academic portfolios.

10 · Defense-in-Depth Exam Security

Built for strict, cheat-proof practical exams.

🛡️

1. Isolated Container Sessions

Every student launches into an independent Linux container with strict CPU, RAM, and disk boundaries. Zero shared folders or cross-session visibility.

🔒

2. Kernel Network Sandboxing

Host-level iptables firewall rules block lateral student-to-student traffic—preventing LAN chat, SSH copying, or local file sharing.

🚫

3. One-Click Internet Lockdown

During practical tests, instructors cut outbound internet and external AI access while keeping the local exam portal and compilers fully active.

🧹

4. Verified Login & Auto-Wipe

Students authenticate with verified college emails and classroom codes. When the exam timer hits 00:00, non-persistent labs wipe automatically.
